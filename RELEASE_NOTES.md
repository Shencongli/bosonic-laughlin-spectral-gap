# The Bosonic Laughlin Spectral Gap: A Candidate Proof

Version 0.1 — 7 October 2026

**Prepared and curated by Xin Shen**

**AI-generated candidate proof.** First public research-note release,

The proposed bound is H_Q^2 >= H_Q/3 for every integer Q >= 3088,
uniformly in particle number, for the complete spherical bosonic V0
Hamiltonian with coefficient one for each unordered pair projector.
At Laughlin flux Q = 2(N-1), this would imply a gap of at least 1/3
for N >= 1545.
